## Limitations

Activity is repository-level default-branch history, including inherited and
automated commits; it is not a maturity score or a nested-project work count.
The current crawler still discovers afresh, so inaccessible or undiscovered
historical entries are not automatically retained. Direct refresh of a known
repository set remains the separately planned incremental-maintenance work.
No homepage ranking, topic/name-based exclusion policy, or duplicate-merging
rule was introduced. Local reviewer decisions and generated review pages were
not changed by this refresh.
